       - Flex - Flexbox (Flexible Box Layout) is a CSS layout system used to arrange, align, and distribute space between elements inside a container. It makes it much easier to create responsive layouts without using floats or positioning.Flexbox is a one-dimensional layout system used to arrange elements in a row or a column while controlling their alignment, spacing, and size.

         - There should be a container tag
         When display: flex; is applied:
                    The parent becomes the flex container.
                    The child elements become flex items.
   
            -  Properties - Flexbox
               - display: flex - Converts a normal container into a flex container.
               - flex-direction - Determines the direction in which flex items are placed.
               - justify-content - Controls alignment in horizontal
               - align-items - Controls alignment in vertical
               - flex-wrap - Determines whether items stay on one line or move to the next line.
               - gap - Adds spacing between flex items.
       
       - Grid - CSS Grid is a two-dimensional layout system used to arrange elements into rows and columns.Unlike Flexbox, which works in only one direction (row or column), Grid allows you to control both rows and columns at the same time.
       There Should be a container element
           Display - Grid
           grid-template-columns - Defines the number and width of columns
           grid-template-rows  - Defines the number and height of rows
           grid-row - The grid-row property tells a grid item where it should start and end vertically.
           fr - The fr (fraction) unit divides the available space into equal or proportional parts.


      - Position 
         
       - Fixed - A fixed element is positioned relative to the browser window, it stays in the same position even the page is scrolled
       - Sticky - A sticky element is behaves like relative until a specified scroll position is reaches, after that its behaves like fixed
       - Static - Static is the default position of every HTML Elements, appears on the normal document flow, top-bottom-right-left does not work
       - Relative - A Relative element stays in a normal document flow, but can be moved from it's original position using top, right, left, bottom
       - Absolute - An Absolute element is removed from the normal document flow, it is positioned relative to its nearest positioned parent.If no positioned parent exists, it is positioned relative to the entire webpage
          - Values - Top, Bottom, Right, left

       - CSS Units - These defines the size of elements such as width, height, margin,padding, fontsize, and spacing 
           Absolute Units - These remains Fixed
             eg : px, cm, in
           Relative Units - These depends on another value
             - Percentage(%) - Relative to the parent element
                eg- Width:50%, if the parent is 400px then width=200px
             - rem - Relative to the root (html) font size
                  eg: html{
                    fontsize:16px
                  }
                  h1{
                    fontsize:2 rem
                  }
                    Result : 2*16 = 32px
             - em - Relative to the parent font size     
                  eg : Parent - fontsize:20px  
                    child - fontsize:2em
                      Result = 2*20= 40px
             - vW - viewport Width
                   1vw = 1% of the browsers width         
                     if the browser width is 1000px then 50vw=500px
             - vh - Viewport height       
                    1vh = 1% of the browsers height    
             - fr (fraction unit) - fraction of available space (only uses in CSS Grid)

- Handling Functions in JavaScript
  - Synchronous functions - Functions execute line by line ,each statement will wait for the current execution to completely
  - Asynchronous functions - allows other code to runwaiting for the time consuming task to complete (timer,api)
  - Call stack - used to execute JS functions in js engine,there is only one call stack to handle (LIFO : Last In First Out)
  - Queue(First In First Out) - when callstack is occupied other task should wait
      - Callback queue - used to store Timer functions, Dom Events
      - Microtask queue - used to store Api calls , it have high priority than Macrotask
  - Event loop : it is an infinte loop used to check
                - if callstack is empty
                - if yes,execute all task in Microtask
                - then execute one task from macro task
                - repeat

- Handling of Asynchronous functions in js
    - using callbacks - used to handle Asynchronous functions,when functions depends each other the function calls gets nested , this problem is called callback hell
    - using Promise : used to handle Asynchronous function , it always returns a response either success or failure
                    : has 3 phases
                      - pending : when we make asynchronous call before it resolves
                      - Resolved/fullfilled : indicate response received from promise,to access the resolved state in js,use "then" method 
                      - Rejected : indicate promise failed, to access rejected state in js , use "catch" method


  - Using async/await - It is an cleaner syntax for working with promises.It does not replace promises internally . async/await allows us to write promise based asynchronous code in a style that looks more like synchronous code
                      - async - we normally puts async before a function,that function works with promises and always returns a promise
                      - await -  means wait for this promise to settle and give me its result before continuing the async function

    -PATCH : Similar as PUT

- Request : consist of two parts "head" and "body"
  -header part - keep secret data
  -body part - used to share data from one to another
- Response -Every response contains a status code, a statud code is a 3 digit number send by the server in the response to tell the client that what happened to its Request

      - 1xx - Information  : indicates that the server has received / understood the request and is continuing to process it
      - 2xx - Success
            - 200 OK : The request was successfull
            - 201 created : When a new resource has been created , usually associated with POST
            - 204 No Content : the request was successfull , but there is no response body
      - 3xx - Redirection
      - 4xx - Failed due to client errors
            - 400 Bad request : the server cannot process the request becouse the request is invalid
            - 401 Unauthorized : the request requires authentication , or the given credentials is invalid
            - 403 Forbidden : the server understood the request bud refuses to allow access
            - 404 not found : The request doesnot exist
            - 405 Method not allowed : The server knows the resource, but the particular HTTP method is not allowed for it
      - 5xx - Failed due to server errors
            - 500 Internal server error : something unexpected went wrong on server
            - 502 Bad Gateway : A server is acting as a gateway/proxy received an invalid response from an upstream server
            - 503 Service unavailable : The server is temporarily unable to handle the request

                REACT - FRONTEND TECHNOLOGY
--------------------------------------------------
1.React is a open source JS library used to build dynamic user interfaces for single page application
      - Frontend : it is the part of a website that users can see and interact with
      - Library : is a collection of prewritten code that can use in our application instead of written everything from scratch
      - Open source : means the source code of a project is publically available under a license that allows specified form to use, modification and distribution
       - Single page application : is a web application where the browser loads the main page once , and when the user interacts with the application , the required content is updated dynamically without reloading the entire webpage

       - Developed by META 
       - First released in 2013

2. Features of React
      - One way data binding : Parent only shares data to child component and vice versa is not possible
      - Component based architecture : means building an application by dividing its UI into small , independent and reusable components
      - JSX (Javascript XML) : It is a syntax extension for javascript that allows us to write HTML-like markup inside javascript code
      - Virtual DOM : It is a light weight javascript representation of the UI that reacts keep in memory
                    Reconciliation : it is the process react uses to determine that needs to change when the UI is updated

6. JSX rules :
    - JSX must return a single parent tag (container tag / react fragments(nameless tags))
    - every tags must have a closing tag (self closing tag <tag/>)
    - we can add js expression inside JSX code using single curly braces (eg : <h1>{js expression}<h1/>)
    JSX use camelcase for jsx attributes and css properties, instead of 'class' attribute jsx uses 'className',instead of 'for' attribute uses 'htmlFor' in jsx

7. Styling for react components :
    1.Inline CSS : Use style attribute,follow camelcase to provide css style,style should be applied as object
    2.External CSS : To link external CSS to a component using import statement , import 'filepath'
    3.External CSS Module file : file extension as .module.css,import module file to component file
                              syntax : import variable-name from 'file path'
    4.CSS library (bootstrap,tailwind etc)

8. Lifecycle phases of react (class) components : Describes the phases of component experience during its creation,updation ,Deletion
              - Creation - Mounting : Component created and inserted in DOM (Component-->Render-->jsx-->insert to DOM-->Display in browser)
              - Updation - Updating : components detect change,react compare old Virtual DOM with the new virtual DOM and apply reload only at the change part of the DOM(Component mounted-->identify changes-->component rerender-->UI updated)
              - Deletion - Unmounting : Removing component from DOM (Component removed-->component unmounted)

9.Props : used to share data from a parent component to child component in react app, props are properties of component,Its an object,props can be given in functional component parameter

10.Event Handling : Depends upon the function which is used to bind the event
                  - Binding function without argument : event = {function-name}
                  - Binding function with argument : event = {()=>{function-name(arg)}}


11. State : It is used to store dynamic values in component, whenever the state changes , components re render 

12.  Hooks : they are Predefined functions used in functional component in order to use react components features in functional components, all hooks functions names startsWith 'use' keyword, for different features different hooks is used

  - Custom Hooks : - These are hooks with JavaScript functions that let you reuse stateful logic between multiple components
                   - these are userdefined hooks
                   - create a js file with name starts with 'use' keyword,define a function and export the same 

                   
              - Rules to call hooks in functional component
                  - Import the hooks
                  - Hooks should be used in the top level of the component
                  - Hooks cant be Conditional

        - Common hooks : 
                  
              1.useState : used to create and manage state in functional component and it returns a statefulvalue, and a function to update it. inorder to update state,call the state updating function with argument as new value
                      syntax : const [statefulvalue, state updating function] = userState(initial value)
                  
              2.useMemo : used to memorize an expensive calculation result of a component and only perform when its dependency changes, hook returns a value       syntax : useMemo{()=>{expensive calculation},[dependency]}

                  dependency can be 2 types
                      1.empty array:useMemo works only at the creation of component
                      2.array with state/props : useMemo works when the state/props value changes
                      3. useCallback : used to memorize an expensive calculation function of a component and only perform when its dependency changes , hook returns a function
                      4. useRef : used to refer real DOM Element, it wont allow re rendering component when its value changes
                                syntax : refData = useRef(), it returns reference of DOM Element, and it is an object.its 'current' key will give us the details which DOM Element is fetched
                      5.UseEffect : used to apply side effects to a functional component,it can be used to get component life cycle methods in functional component
                              syntax : useEffect(callback,dependency)
                            -dependency can be different types 
                              - no dependency : side effects will apply to the component all the times
                              - empty array : side effects will apply at the time of the component creation,similar to Mounting
                              - [state,props,variables] : side effects will apply at the time of the component creation as well as whenever state,props,variable given in the array changes similar to updating

13. Conditional rendering : Based on condition,displaying contents in jsx,use Ternary operator(?:) or truthy operator (&&)
